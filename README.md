# BGMI Tournament Promotional Poster

This project was created as part of the SoftGrowTech Graphic Designing Internship.

## Project Overview
A promotional poster designed for a BGMI Esports Tournament to attract players and create excitement for the event.

## Project Details
- Project Type: Poster / Banner Design  
- Theme: BGMI Esports Tournament  
- Tool Used: Canva  
- Design Style: Gaming, Esports, Promotional  

## Features
- Bold esports-themed poster design  
- Trophy and fire-themed visuals  
- Tournament details and prize information  
- Dark gaming-inspired background  

## Description
This poster was created to promote a BGMI tournament named "Chaotic Desire". It includes tournament details, prize pool, registration call-to-action, and an esports-style visual design.
